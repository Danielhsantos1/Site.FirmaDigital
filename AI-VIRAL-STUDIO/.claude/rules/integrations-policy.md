# Política de integrações

- Integrações vivem em `integrations/` e hoje são **somente documentação**.
- Proibido: chamar API paga, criar contas, configurar chaves ou executar geração externa sem aprovação explícita do usuário no turno corrente.
- Chaves: apenas variáveis de ambiente; jamais em arquivos versionados.
- Antes de qualquer implementação, o arquivo da ferramenta deve ter todos os campos de "Requisitos" preenchidos com fonte oficial e data.
- Ferramenta sem API oficial confirmada (ex.: edição em apps de terceiros) é tratada como fluxo manual assistido, com entregáveis exportáveis (listas de corte, legendas, roteiros de gravação).
